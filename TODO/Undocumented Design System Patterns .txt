  Undocumented Design System Patterns

  1. Frosted Glass Card Effect

  Used in about-me and contacts for premium card feel, but not documented:

  /* Pattern observed in about-me .content-wrapper, contacts .contact-methods */
  background: rgba(255, 255, 255, 0.7);  /* or 0.85 */
  backdrop-filter: blur(10px);
  -webkit-backdrop-filter: blur(10px);

  Where documented? Nowhere. The DESIGN_SYSTEM.md only shows solid background: white for cards.

  3. Photo Frame with Offset Border

  Distinctive pattern used in about-me and contacts:

  .photo-frame {
    position: relative;
    &::before {
      content: '';
      position: absolute;
      top: 10px;      /* Offset creates "shadow" effect */
      left: 10px;
      right: -10px;   /* Extends beyond container */
      bottom: -10px;
      border: 3px solid var(--color-gold);
      border-radius: 0.5rem;
      z-index: 0;
    }
  }

  Visual effect: Gold rectangular frame offset to bottom-right of photo.
  Responsive scaling: Offset increases from 10px → 14px → 18px at breakpoints.

  Where documented? Nowhere.

  6. Ambient Glow Animation

  Floating decorative background elements in about-me:

  .ambient-glow {
    position: absolute;
    border-radius: 50%;
    filter: blur(80px);
    pointer-events: none;
    animation: float-glow 8s ease-in-out infinite;
  }

  @keyframes float-glow {
    0%, 100% { transform: translate(0, 0) scale(1); }
    50% { transform: translate(20px, -20px) scale(1.1); }
  }

  Where documented? Nowhere. Only static .section-glow is documented.

  7. CTA Frame with Corner Accents

  9. Staggered Entrance Animation Pattern

  Used extensively for card grids:

  .card {
    animation: cardEntrance 0.5s var(--ease-standard) backwards;

    &:nth-child(1) { animation-delay: 0.1s; }
    &:nth-child(2) { animation-delay: 0.2s; }
    /* ... up to 8 children */
  }

  Where documented? Only badgeReveal, titleReveal, introReveal are documented. The general staggered pattern is not.
