# December design cleanup: regression check

> Appendix to [`../audit-report-2026-10.md`](../audit-report-2026-10.md). Rows were derived from the CSS with file:line evidence; the findings re-checked in a browser are listed in the main report (§7).

**Checked:** 2026-10-12, read-only, against the current working tree.
**Sources:** `docs/design-system/audit-report.md` (2025-12-21), `normalization-log.md` (fixes logged 2025-12-22 to 12-24), `visual-review-desktop.md` (2025-12-24).
**Method:** I flattened all 50 style sources into 8,536 declarations (file, line, selector, media, property, value) with a one-off extraction script. The 50 sources are the 25 `.css` files in `src/app`, the 24 components with inline `styles:` and `src/styles.css`. I also grepped templates for `style=`, `[style.*]` and `iconStyles`, and checked that every file path cited in the log exists.
**Dating limit:** git history is shallow (root `c3eece8`, 2026-04-28). `git log -S` puts every drift below at or before that root, so it cannot date them. A finding counts as post-cleanup only when the code itself proves it:
- an override or clone of the CTA components, which were created on 2025-12-22/23;
- anything on `/consultation/`, which was planned with a sitemap date of 2026-01-15 (`docs/new-contact-form-implementation/sequential-jingling-whistle.md:838`).

**Status legend**
- **HOLDS:** Every logged claim is still true. That covers the token value, the logged files and selectors using the token, and the removal of legacy code. No value that looks different appears in the same role anywhere in `src/app`. A hardcoded copy with the token's exact value is noted but does not lower the status.
- **PARTIAL:** The logged scope is largely intact, but one of these applies:
  - a token value or logged usage has drifted from the log;
  - off-standard values in the same role exist elsewhere in `src/app` and cannot be shown to postdate the cleanup. These are unnormalized, not regressed.
- **REGRESSED:** The standard has been visibly undone in code that provably postdates the cleanup, or a logged file no longer uses the token.
- **NOT-APPLICABLE:** The logged file or selector is gone.

**Result (14 log items):** HOLDS 2 · PARTIAL 9 · REGRESSED 3 · NOT-APPLICABLE 0.
At sub-reference level, 2 references are N/A: `documents-section.component.html/.css` never existed separately, and `.intro-badge` was renamed.

**Summary:** The home-page sections, which are the logged scope, are still almost fully normalized. The drift falls into four groups:
1. The CTA standard is overridden or cloned on newer pages (/about-me/, blog posts, /consultation/).
2. Logged colour values are hardcoded again, on /consultation/, the footer, the spinner and the FAQ accordion.
3. Two token values or usages changed without any doc update: mobile `--section-padding-y` is now 1.5rem, and the intro H1 underline uses the 100px accent width.
4. The cleanup never reached the rest of the site (section 3).
